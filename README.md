# HCSAtlas · HSC aide-mémoire

A diagnostic quick reference for congenital adrenal hyperplasia (CAH) and its differential diagnoses (interface in French).

**Open it:** https://clairevaltin.github.io/HCSAtlas/

## What it does

- **Interactive steroid pathway map** – pick an enzyme block to see which precursors build up and which hormones fall
- **Fact sheets** for each form of CAH (21-hydroxylase, 11β-hydroxylase, 17α-hydroxylase, 3β-HSD, StAR, POR, and others)
- **17-OHP interpretation** – basal and post-Synacthen thresholds, with unit conversion
- **Diagnostic orientation** and **frequencies**
- **Treatment** – glucocorticoids, mineralocorticoids, salt, and stress dosing in emergencies
- **Differential diagnoses** outside CAH
- An FAQ with sources

## How to use

Open the link above. Nothing to install.
